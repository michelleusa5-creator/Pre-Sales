## PART 1：开篇——问题定义

### P3 — 三个不知道 + 算法视角重构

**左侧：**
- 现象：湾仔码头部分产品已退出山姆会员店极速达渠道
- 三个不知道：
  - 不知道现在货架上的真实竞争格局
  - 不知道极速达选品逻辑受哪些因素驱动
  - 不知道消费者为什么选择或放弃湾仔码头
- 结论：没有这三个答案，任何行动建议都是猜测

**右侧（视角转换对比框）：**

| 传统视角 | 我们的视角 |
|---|---|
| 发生了问题 → 拉数据 → 做报表 → 逐一回答 | 极速达 = 评分系统 → 退出 = 分数低于阈值 → 问题 = 哪个因子失分 |

**底部命题一句话：**
用可观测数据反推极速达选品算法，找出失分因子，定义改善路径——同时系统性回答 RFP 提出的五个核心挑战。

## PART 4：方法论细拆——四因子群

### P11 — 因子群一：履约供给类（上）

> 对应 Challenge 2：Warehouse, Fulfillment & Assortment Driver Analysis

**左侧：核心观测指标**

| 指标 | 计算或记录方法 | 主要用途 |
|---|---|---|
| 当前极速达状态 | 按地址记录标识、配送及核验结果 | 识别当前表现 |
| 监测地址覆盖率 | 已核验支持极速达的地址数 ÷ 已完成核验的监测地址数 | 观察固定地址样本内覆盖变化 |
| 缺货观察占比 | 显示缺货的有效观察数 ÷ 有效库存观察数 | 对比可售稳定性 |
| 状态变化次数 | 在可比条件下统计标识/配送/可售状态切换 | 识别稳定性 |
| 连续异常观察跨度 | 从首次异常至最近一次异常的时间跨度 | 判断异常是否持续 |
| 恢复记录 | 记录恢复时间、恢复地址和对应配送状态 | 追踪处理与自然恢复情况 |

**右上：极速达状态四分类**

| 状态类别 | 观察与核验方式 |
|---|---|
| 已核验支持极速达 | 指定地址下配送或结算信息确认支持 |
| 观察到极速达标识 | 商品页面显示标识，待进一步核验 |
| 暂时不可售或不可配送 | 显示缺货、时段或地址限制等提示 |
| 状态待核实 | 页面标识或配送信息不足或相互不一致 |

**右下：跨城市判断逻辑**

| 上海状态 | 杭州状态 | 业务判断 |
|---|---|---|
| 极速达 | 次日达 | 前置仓有货，云仓缺货 |
| 次日达 | 无货 | 云仓缺货 |
| 无货 | 有货 | 前置仓缺货 |
| 均无货 | — | 结合历史记录判断是暂时缺货还是实质退出 |

### P12 — 因子群一：履约供给类（下）——长尾 SKU 状态识别

**左侧：长尾 SKU 状态识别逻辑**

用历史排名分层（头部/中部/尾部）+ 极速达标识时间轴，区分三种状态：
- **暂时缺货**：短期内恢复，状态波动频繁但不持续
- **覆盖收缩**：标识消失后未在多周内恢复，影响范围限于部分城市
- **实质退出**：所有监测地址均无极速达标识，持续时间超过观察阈值

结论：中尾部 SKU 一旦进入「覆盖收缩」状态，恢复周期显著更长；头部 SKU 通常能快速恢复。

> 【产品截图占位 1-B】SKU 极速达状态时间轴图（Mock，横轴为时间周次，纵轴为 SKU，标注各 SKU 的极速达状态变化节点，区分头部/中部/尾部颜色，标注「暂时缺货」「覆盖收缩」「实质退出」三类状态区间）

### P16 — 因子群三：消费者声音类（下）——Product Remarkability 映射

## PART 5：诊断逻辑——从指标到结论如何运转

### P19 — 六个诊断维度 + 三种对照方法 + 五类异常触发

**左上：六个诊断维度**

| 分析维度 | 关注内容 | 诊断作用 |
|---|---|---|
| 区域可售与履约 | 地址差异、缺货、配送变化及恢复 | 优先确认异常范围与状态 |
| 商品表现 | 排名、销量档位、客户销售变化 | 观察需求和经营表现 |
| 口碑与品质 | 好评率、问题主题及集中发生情况 | 定位体验改善机会 |
| 价格与规格价值 | 单位价格、分装、规格、价值反馈 | 识别价格及使用价值变化 |
| 竞争与差异化 | 竞品上新、覆盖、排名及卖点 | 识别替代压力与差异化机会 |
| 消费者反馈活跃度 | 7 天评论量同比、环比、主题变化 | 发现值得进一步观察的变化 |

**右上：三种对照方法**

| 方法 | 操作方式 | 解决的问题 |
|---|---|---|
| 自身前后对照 | 比较状态变化前后及行动前后的指标 | 哪些变化先发生，改善后有什么结果？ |
| 同期同类对照 | 选择相近品类、规格、价格带或场景商品 | 是本品变化，还是品类共同变化？ |
| 同商品跨地址对照 | 在固定时间窗比较同款商品不同地址 | 是局部现象，还是更广泛变化？ |

**下方：五类异常事件触发条件**

- 极速达标识、配送方式或实际可配送结果发生变化
- 缺货或不可售在连续观察中持续出现
- 多个地址或多款商品同步发生变化
- 排名、好评率、价格或竞品表现出现持续变化
- 评论活跃度同比/环比出现明显变化

### P20 — 7 步诊断流程 + 标准诊断记录格式

**左侧：7 步诊断流程（步骤图）**

```
1. 复核数据 → 检查采集完整性、商品规格、地址和时间口径
2. 确认事实 → 记录变化内容、首次时间、持续情况和影响范围
3. 建立对照 → 自身历史 / 同类商品 / 其他监测地址
4. 提出假设 → 围绕可售、表现、口碑、价值、竞争列出解释
5. 辅助验证 → 结合客户销量、渠道、促销等经营信息检验一致性
6. 形成建议 → 按证据和可执行程度安排核查、改善及持续关注
7. 复查结果 → 观察状态、消费者反馈与经营表现的后续变化
```

**右侧：标准诊断记录格式（格式卡片）**

每个诊断事件采用统一格式：

```
观察事实 → 分析假设 → 支持证据与反例 → 待补信息 → 建议行动 → 验证指标 → 后续结果
```

标注规则：「已观察事实」/ 「有证据支持的判断」/ 「待验证假设」三类分别标注，使业务使用者可以快速理解结论依据。

### P22 — 失分因子下钻诊断

**左侧：因子群一（履约供给，Mock 72 分）失分原因**

- 缺货观察占比偏高（尤其北京、成都）
- 云仓补货周期不稳定，导致极速达标识频繁消失
- 覆盖收缩已持续多周，未见自然恢复迹象

**右侧：因子群三（消费者声音，Mock 68 分）失分原因**

- 「皮厚馅少」「煎糊粘锅」差评集中，样本问题提及率高于同类竞品均值
- 好评率低于品类均值
- 「晚归独食」场景下回购意愿表达明显偏低

> 【产品截图占位 6-B】因子下钻明细表（Mock，展示每个子因子的得分及对应证据来源，例如「缺货观察占比：北京 38%，成都 41%，参考值 <15%」；「样本问题提及率（煎糊粘锅）：湾仔 32% vs 竞品均值 11%」；数值均为 Mock 示意）

### P23 — 诊断结论

**核心结论框：**

> 湾仔码头退出极速达是**「履约不稳定 + 消费者口碑下滑」叠加效应**的结果，不是单一原因。

**方法论价值说明：**

这套分析给出的不是「销量下降」这种现象描述，而是：
- **哪个因子**：履约供给类（72/100）+ 消费者声音类（68/100）
- **哪个子因子**：缺货观察占比偏高 / 差评主题集中
- **什么证据**：多城市状态记录 + 评论分析数据

这个诊断链条同时为四个团队提供了行动起点：

| 团队 | 对应失分因子 | 行动方向 |
|---|---|---|
| Sales & EC | 因子一（履约供给） | 渠道沟通 + 覆盖恢复 |
| R&I | 因子三（消费者声音） | 产品升级优先级 |
| Marketing | 因子三（消费者声音） | 口碑改善 + 场景化营销 |
| Demand Forecast | 因子一/二（履约+交易） | 需求预测辅助信号 |
