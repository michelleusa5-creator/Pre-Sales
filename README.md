# Pre-Sales（售前工作台）

本仓库用于 Cursor Project「pre-sales」：沉淀可复用的售前素材，并按客户产出方案。

## 目录结构

```
Pre-Sales/
├── 01 materials/          # 可复用素材（从本地公司素材库同步）
│   ├── 01 intro/          # 公司介绍
│   ├── 02 products/       # 产品能力（CDP / MA / Agents / 数仓等）
│   └── 03 cases/          # 行业案例
│       ├── 01 FMCG/
│       ├── 02 fashion/
│       └── 03 beauty/
├── 02 templates/          # 方案/Workshop/打标模板
├── 03 proposals/          # 按客户存放输出稿（勿放敏感合同原件）
└── 04 playbook/           # 售前流程与检查清单
```

## 使用方式

1. 把可复用素材放进 `01 materials/`（案例请脱敏）
2. 在 Cursor 打开本仓库对应的 Project `pre-sales`
3. 新客户方案输出到 `03 proposals/客户名/`

## 注意

- 不要上传客户合同、报价原件、含 PII 的原始数据
- 产品文档以最新版为准；旧版放入 `_archive/`
